# 1. Purpose

The Memory & Knowledge System allows Vault AI to remember important information and use relevant context to provide better answers.

The system is designed around local storage and retrieval.

The main objective is:

```text
Store Important Information
        ↓
Process / Index
        ↓
Retrieve Relevant Information
        ↓
Combine With Current Question
        ↓
AI Generates Better Response
